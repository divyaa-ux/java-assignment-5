- Encapsulation

- Data Validation

- Hybrid Inheritance

- super Keyword

## Software Requirements

- Java JDK 8 or above
- IntelliJ IDEA, Eclipse, or VS Code

## How to Run

1. Install Java JDK.
2. Open the required Java file in your IDE.
3. Compile and run the program.

Example:

    javac Q01_StudentEncapsulation.java
    java Q01_StudentEncapsulation

Replace the file and class name to run another program.

## Conclusion

These programs demonstrate the fundamental
Object-Oriented Programming concepts in Java.
